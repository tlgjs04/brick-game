# 벽돌깨기

먼작귀 캐릭터가 나오는 브라우저 벽돌깨기 게임입니다. `index.html` 파일 하나로 동작하고, 설치나 빌드가 필요 없습니다.

- 조작: 왼쪽·오른쪽 화살표 키, 마우스, 휴대폰에서는 손가락으로 끌어서 막대를 움직입니다.
- 규칙: 「시작」을 누르면 공이 움직이고, 벽돌 하나에 10점, 목숨은 3개입니다. 벽돌을 다 깨면 공이 더 빨라진 2단계가 시작됩니다.

## 배포 (GitHub Pages)

저장소 Settings → Pages → Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 두고 저장하면 `https://<계정>.github.io/brick-game/` 주소로 열립니다.
